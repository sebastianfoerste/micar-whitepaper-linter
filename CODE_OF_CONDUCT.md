# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion about the work. Do not post confidential client material or real unpublished whitepapers in issues or pull requests.

Report unacceptable behaviour privately to the maintainer through the contact in [SECURITY.md](SECURITY.md). Reports are handled confidentially.
