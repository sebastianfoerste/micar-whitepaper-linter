MARKETING.CONSISTENCY

Consistent with the white paper: identifiers, dates, percentages, amounts and contact details found in the white paper

How the status is set

  • Missing: the text is empty or holds only placeholders such as TBD.
  • Review: the white paper given with the communication does not contain an identifier, e-mail address, web host, telephone number, date, percentage or amount of the communication; the finding names up to ten of them and counts the rest.
  • Pass: the white paper contains every such value, or the communication holds none.
  • Not run: no white paper was given (--whitepaper). The report says so and lists the rule under not_run.

Limitations

  • Reads the whole text of the marketing communication as a reader sees it: the text value of a JSON file, or the text of a Markdown, text, HTML, XHTML, DOCX or PDF file without what the loader finds a reader cannot see. It cannot see layout, placement, prominence, images, audio or video, so wording shown only in an image, a banner or a voice-over is not read.
  • Compares only values it can read: LEIs with valid check digits, nine-character codes of capital letters and digits such as a DTI, e-mail addresses, web hosts, international telephone numbers (+ or 00), calendar dates, percentages and amounts with a currency code or symbol (EUR, USD, GBP, CHF, USDC, USDT, €, $, £, with million and similar words). A value counts as found where the white paper contains it anywhere: a web host also inside an e-mail address, a date in any form the check reads, an amount or a percentage of the same value. It does not compare statements, names or descriptions, so a claim that the white paper does not support passes where it holds no such value. It does not run without a white paper (--whitepaper).
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • The marketing communication checks have not yet been run against a real marketing communication.
