How the status is set

  • Missing: in a numbered-field XHTML draft, no field with a closed list is present under its number with the template's English or German name as its label, or with no label.
  • Review: such a field holds an answer that is not of its type (below). An empty field, a placeholder and an answer marked not applicable are not checked here; the other rules report missing answers. The finding names the field and the expected type, never the answer.
  • In a draft without field numbers (JSON, PDF, DOCX, Markdown, heading-based XHTML): Missing where section offer_or_admission is absent, empty or holds only a placeholder, otherwise Review with a note that the field-level check needs the numbered-field layout. Such a draft never passes.
  • Pass: every such field the draft carries holds its type.

Limitations

  • Reads the fields of a numbered-field XHTML draft by their numbers; text elsewhere is not considered. In a draft without field numbers it reads section offer_or_admission only to tell whether it is absent.
  • Reads the text a reader sees. An Inline XBRL document can show a tagged value in another form than the value it reports, through a transformation; the check does not read the tags, so a reviewer confirms the tagged value of each field it reports.
  • Skips a field whose label is not the template's English or German name for its number: the draft numbers its fields otherwise. A field without a label is checked by its number alone, so a draft that renumbers and leaves out labels can be checked against the wrong type.
  • A code counts in any case at the start of the field, before a description after a dash, colon or bracket; several codes joined by commas or “and” pass. The German Official Journal writes the submission code EROR as ERROR; both pass.
  • A Member State counts by its English or German name, its ISO 3166-1 alpha-2 code or EL; Iceland, Liechtenstein and Norway count too, and so do phrases such as “all EU Member States”. The taxonomy's closed list itself is not printed in the Official Journal.
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • The template checks have not yet been run against a real notified white paper; for Tables 3 and 4 they follow the Official Journal text only.
