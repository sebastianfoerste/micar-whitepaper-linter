How the status is set

  • Missing: no LEI-shaped code (18 upper-case letters or digits and two check digits) appears in any section, and no section issuer, offeror or trading_platform_operator has text other than a placeholder. A 20-digit number counts only in a section that reads LEIs (below). A malformed code (below) is named in the finding but does not change this status.
  • Review: an LEI-shaped code fails the ISO/IEC 7064 MOD 97-10 check digits; an LEI-like code in a section that reads LEIs is malformed; or no LEI-shaped code appears while a party section has text, since point 5 allows another identifier required pursuant to applicable national law in place of the LEI. A section reads LEIs if it is issuer, offeror or trading_platform_operator, names an LEI label (LEI or LEIs, legal entity identifier or ID, Rechtsträgerkennung, in any case, also split by hyphens or line ends) or holds an LEI-shaped code with a letter. There every LEI-like code counts, wherever it stands: a run of 18 to 22 letters and digits that holds a digit or no lower-case letter, or groups joined by spaces (also invisible ones), hyphens or a line end that together hold at least 18. It is malformed unless it is one LEI-shaped run: of 18, 19, 21 or 22 characters, in lower case, with a letter where a check digit belongs, or split into groups.
  • Pass: every LEI-shaped code has valid check digits and no LEI-like code is malformed. No registry is asked.

Limitations

  • Reads every section of the draft; findings are anchored to the issuer section.
  • Works offline on the characters of each code. It does not confirm that an LEI is registered, current or held by the entity the draft names.
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • Does not recognise the other identifiers that point 5 allows in place of the LEI, so a draft without any LEI goes to review once a party section has text. Once the draft gives one LEI, a party section without an LEI of its own does not change the result.
  • Reads section text only. A heading and text in no section are not read, so a code on a line that the loader takes for a heading (in a PDF, a line such as Offeror: ... that names a section) is not seen. A malformed code is not seen in a section that is not a party section, names no LEI label and holds no LEI-shaped code with a letter, nor when it is no LEI-like code: one run of fewer than 18 or more than 22 letters and digits, as when a code has lost or gained three or more characters, also right after a label; groups that together hold fewer than 18; a run of letters only with a lower-case letter, which reads as a word; groups split by other characters, such as full stops or slashes, by more than three characters, or by two hyphens or two line ends (a blank line); or a code split into groups where a group of letters only with a lower-case letter stands beside no group of its length with a digit. Groups in capitals without a digit count only if all have the same length. Every LEI-like code in a section that reads LEIs counts, so an IBAN, a long number in groups, a placeholder such as XXXXXXXXXXXXXXXXXXXX, or an address or a heading in capitals with a digit in it gives Review too, which fails safe.
