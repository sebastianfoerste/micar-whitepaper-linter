How the status is set

  • Missing: no LEI-shaped code (18 letters or digits and two check digits) appears in any section. A 20-digit number counts only next to an LEI label.
  • Review: an LEI-shaped code fails the ISO/IEC 7064 MOD 97-10 check digits.
  • Pass: every LEI-shaped code has valid check digits. No registry is asked.

Legal basis

ReviewCheck digits do not match

The last two digits do not satisfy ISO/IEC 7064 MOD 97-10, which usually means a typo.

{
  "title": "Synthetic rule example",
  "type": "other",
  "sections": {
    "issuer": "Synthetic Issuer AG. LEI: 9999SYNTH0000ZZQ0167."
  }
}
PassCheck digits match

The code is well formed. The check does not ask a registry whether the LEI exists or belongs to the named entity.

  "title": "Synthetic rule example",
  "type": "other",
  "sections": {
    "issuer": "Synthetic Issuer AG, a fictional company. LEI: 9999SYNTH0000ZZQ0166."
  }
}

Limitations

  • Reads every section of the draft; findings are anchored to the issuer section.
  • Works offline on the characters of each code. It does not confirm that an LEI is registered, current or held by the entity the draft names.
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • The citation is the Part of each Annex that the party rules already cite. The point that names the LEI has not been verified against the Official Journal; treat the legal basis as pending owner review.
