How the status is set

  • Missing: in a numbered-field XHTML draft, every field below that applies is empty, absent or holds only a placeholder such as TBD.
  • Review: in a numbered-field draft, a field that applies is empty, absent or holds only a placeholder; a field that applies is marked not applicable (N/A, none, a dash) where the template does not ask for it “where applicable” or “if any”; or no field of an alternative holds an answer. A field that applies only under a condition is checked as applying when the draft does not show the condition (a flag that is neither true nor false, a code field without a template code). The finding names each field by its number and, in English, the template's name.
  • Not run: in a draft without field numbers (JSON, PDF, DOCX, Markdown, heading-based XHTML) the check does not run. The report has no finding for this rule, neither open nor passed; one note names how many field-level checks did not run.
  • Pass: every field that applies holds an answer. A field that does not apply under its condition is not reported; the finding names the condition. An LEI counts as given only with valid check digits, a DTI as nine letters or digits; true and false count also as richtig and falsch, yes and no, ja and nein.

The fields of Table 3 of Implementing Regulation (EU) 2024/2984 that carry the point:

  • B.9 (Crypto-asset characteristics)
  • B.7 (Type of crypto-asset white paper)
  • B.8 (The type of submission)
  • B.10 (Website of the issuer)
  • B.11 (Starting date of offer to the public or admission to trading)
  • B.12 (Publication date)
  • B.13 (Any other services provided by the issuer); “not applicable” is an answer
  • B.14 (Language or languages of the crypto-asset white paper)
  • B.15 (Digital token identifier code used to uniquely identify the crypto-asset or each of the several crypto assets to which the white paper relates, where available); “not applicable” is an answer
  • B.16 (Functionally fungible group digital token identifier, where available); “not applicable” is an answer
  • B.17 (Personal data flag)
  • B.18 (LEI eligibility)
  • B.19 (Home Member State)
  • B.20 (Host Member States); “not applicable” is an answer

Limitations

  • Reads the fields of a numbered-field XHTML draft by their numbers, fields B.7, B.8, B.9, B.10, B.11, B.12, B.13, B.14, B.15, B.16, B.17, B.18, B.19 and B.20 of Table 3 and the fields their conditions name; text elsewhere is not considered. It does not run on a draft without field numbers; finding the point's items in free text is not built.
  • Checks whether each field holds an answer, not what it says: an answer to another question passes. ITS.FIELD_FORMATS and ITS.CODE_LISTS check the formats and codes of the typed fields.
  • Does not check a field's label, so a draft that numbers its fields otherwise is read in the wrong fields.
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • The Annex II rules have not yet been run against a real ART white paper.
