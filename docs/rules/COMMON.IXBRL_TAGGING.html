How the status is set

  • Missing: the draft is JSON, DOCX, PDF or Markdown.
  • Review: the draft is XHTML. The check reports namespace problems and always adds that tag completeness was not checked.
  • Pass: never. This is a fail-closed format gate.

Legal basis

Art. 2 Regulation (EU) 2024/2984

  • https://eur-lex.europa.eu/eli/reg_impl/2024/2984/oj/eng

Synthetic examples

Each example is linted when this page is generated. The build fails if a result differs.

MissingAny JSON draft

A JSON, DOCX, PDF or Markdown draft cannot carry Inline XBRL, so the blocker stays open. An XHTML file is checked for the Inline XBRL 1.1 and ESMA MiCA taxonomy namespaces and then shows Review, because tag completeness needs a taxonomy validator.

Limitations

  • Reads no section. It checks the file format, so adding a section to a draft cannot change its status.
  • Checks the file format and taxonomy namespace only, not tag completeness.
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • This rule never reports Pass.
