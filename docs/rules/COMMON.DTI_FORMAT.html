How the status is set

  • Missing: in a draft without field numbers, the section is absent or empty, holds only placeholder text such as TBD or TBC, or opens with the starter template's REPLACE: note. A numbered-field XHTML draft is never Missing on this rule, as both template fields are filled in where available.
  • Review: no DTI is given (both fields empty, a placeholder or N/A, or no code after a DTI or FFG DTI label); a DTI is given without the DTI of its functionally fungible group, or the group code without a DTI of the crypto-asset; more than one group code is given; or a field, or the word after a label, holds anything other than codes of 9 letters or digits.
  • Pass: the draft gives at least one DTI and exactly one group code, each of 9 letters or digits, the {DTI} format of Table 1 of the Annex to Implementing Regulation (EU) 2024/2984. A pass means the codes have that shape, nothing more.

Each template carries the two codes in its own part: fields F.13 and F.14 of Table 2 (Part F, section crypto_asset), B.15 and B.16 of Table 3 (Part B, section art) and B.12 and B.13 of Table 4 (Part B, section emt) of Implementing Regulation (EU) 2024/2984. The check is the same for all three.

Limitations

  • Reads one section key per regime, the part whose template fields carry the codes, and in a numbered-field XHTML draft only those two fields. Text elsewhere in the draft is not considered.
  • Works offline on the shape of each code. It does not confirm that a code is registered with the Digital Token Identifier Foundation, that it belongs to the crypto-asset, or that the group code is of type 3, and it cannot recognise the identifier approved by ESMA that Art. 3(3) of Delegated Regulation (EU) 2025/421 asks for where no DTI is available. ISO 24165 was not read, so no check character is computed.
  • Status and severity are fixed by the rule. A draft cannot waive or downgrade them.
  • In a draft without field numbers a code counts only right after a label: DTI, FFG DTI, Digital Token Identifier or functionally fungible group, with an optional colon, (DTI), (FFG), code, is, ist or lautet in between. A code introduced otherwise, a second code after the same label and a template field name used as a label (Digital token identifier code used to ...) give Review, which fails safe. German drafts are read after the acronyms and the English names only.
