# Review-workspace programme

The white-paper workspace emits a digest-bound collaboration sidecar, document change set and supervised workflow pack. Review cells support locks, assignment, comments and decisions with expected revisions. Source-digest changes mark the sidecar stale.

Tracked DOCX export copies the source package and writes accepted changes only. Rejected changes are excluded. Workflow runs retain the exact definition snapshot, inputs, source references, decisions and audit events. The CLI supports `--workflow-action validate`, `inspect` and `run`. The review tables written by `--review-table-output`, by `--compare-review-table-output` and inside the workspace, and the dates of tracked changes in the DOCX export, use the reproducible-build `SOURCE_DATE_EPOCH` value, defaulting to Unix epoch zero. Other outputs use the current time and so differ from run to run: the workspace vault's own `generated_at`, the audit log, the coverage matrix, the artifact manifest, the directory batch pack, and the time-stamped files of the review bundle (`--review-bundle-dir`), which ignore `SOURCE_DATE_EPOCH`: `compliance-checklist.md`, `coverage-matrix.json`, `review-table.json`, `reviewer-signoff.md` and `manifest.json`. The exported DOCX also differs between runs, because its ZIP entries carry the current file times.

Run `make check`. External filing, notification and publication remain outside the CLI and require qualified lawyer review.
